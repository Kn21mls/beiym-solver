# Политика конфиденциальности Beyim Solver

Beyim Solver помогает разбирать упражнения на Beyim. Доступ к закрытой бете выдаёт сопровождающий проекта.

## Какие данные передаются

- При активации код приглашения отправляется на сервер Beyim Solver. Сервер хранит хеши приглашений и сессий, сроки их действия, отметки отзыва и счётчики запросов. Сессия действует 30 дней или до отзыва. Расширение хранит токен сессии и согласие на обработку локально в браузере.
- При разборе расширение отправляет на сервер текст задания, варианты и при необходимости изображение рисунка. Когда используется снимок вкладки, расширение обрезает его до рисунка перед отправкой. Сервер пересылает материалы в Groq для генерации ответа. [Политика Groq](https://groq.com/privacy-policy/)
- Расширение взаимодействует с элементами задания на странице Beyim. Пароль и cookies Beyim на сервер проекта или в Groq не отправляются.

## Хранение и использование

Сервер проекта не записывает вопросы, снимки и ответы в базу данных или журнал. Ответы могут временно оставаться в оперативной памяти сервера для повторного разбора. Счётчики за предыдущие дни удаляются при последующих запросах. Данные приглашений используются для доступа и лимитов. Данные используются для работы расширения и не продаются.

Для отзыва сессии нажмите «Отключиться» в панели. Чтобы запросить удаление записи приглашения или задать вопрос о данных, обратитесь к сопровождающему, который выдал код, либо воспользуйтесь контактом поддержки из карточки Chrome Web Store.
