# Выпуск Beyim Solver 0.3

## Подключить сервер

Используйте PowerShell 7 на компьютере, который будет доступен тестировщикам. Если окружение ещё не создано, запустите `Install.cmd`.

```powershell
.\.venv\Scripts\python.exe -m pip install -r server\requirements.txt
$env:GROQ_API_KEY = Read-Host 'Ключ проекта Groq Free' -MaskInput
.\Start-beta.cmd
```

Сервер слушает только `127.0.0.1:8787`. В отдельном терминале на этом компьютере запустите [Tailscale Funnel](https://tailscale.com/docs/features/tailscale-funnel). Понадобится вход в Tailscale и настройка Funnel для компьютера.

```powershell
tailscale funnel 8787
```

Скопируйте HTTPS-адрес из вывода и проверьте `/health` с другого подключения. Держите оба процесса запущенными на время ревью и беты.

```powershell
# В новом терминале, из корня проекта
$env:BEYIM_BETA_API = Read-Host 'HTTPS-адрес Funnel'
Invoke-RestMethod "$($env:BEYIM_BETA_API.TrimEnd('/'))/health"
npm --prefix extension ci
npm --prefix extension run package:beta
```

Для подачи используйте `extension/beyim-solver-chrome-beta.zip`. Сборка должна содержать реальный адрес Funnel. Сборка с адресом `https://beta.example.test` создаёт `extension/beyim-solver-chrome-beta-test.zip` для локальной проверки.

## Приглашения

```powershell
.\.venv\Scripts\python.exe -m server.beta issue
.\.venv\Scripts\python.exe -m server.beta list
.\.venv\Scripts\python.exe -m server.beta revoke ИДЕНТИФИКАТОР
```

`issue` печатает идентификатор и код. Код отправляйте только получателю. Приглашение действует семь дней до активации, после активации сессия действует 30 дней. `revoke` отменяет и приглашение, и сессию. Лимит составляет пять активных приглашений. Оставьте отдельное место для ревью, после ревью отзовите код проверяющего и выдайте пятый код участнику беты.

Лимиты API составляют 10 разборов в сутки на приглашение и 50 на всех. Счётчик сбрасывается в полночь UTC. Сервер выполняет один запрос к модели одновременно. База по умолчанию находится в `server/data/app.db`. Все команды должны использовать тот же файл базы, что и процесс API.

## Карточка Chrome Web Store

**Название** — Beyim Solver

**Краткое описание** — Разбор упражнений Beyim с объяснением и отправкой по подтверждению.

**Описание**

Откройте упражнение Beyim и нажмите «Разобрать задание». Расширение покажет, как оно прочитало вопрос, какой ответ предлагает и почему. Вы можете сверить решение и отправить предложенный ответ кнопкой «Отправить ответ». Для поддерживаемых уроков доступно автопрохождение с кнопкой остановки.

Доступ к бете по приглашению. Код вводится один раз. Для разбора текст, варианты ответа и при необходимости изображение передаются через сервер проекта в Groq. В тестах по теме расширение разбирает один вопрос и может выбрать предложенный ответ. Переход и сдача теста выполняются на Beyim.

**Разрешения**

- `activeTab` — получить снимок видимой вкладки по действию пользователя, если рисунок нельзя прочитать напрямую. Расширение обрезает снимок до области рисунка перед отправкой.
- `storage` — хранить сессию, согласие и настройки расширения локально.
- Beyim — читать поддерживаемое упражнение и взаимодействовать с его элементами при отправке или автопрохождении.
- HTTPS-адрес API проекта — обменять приглашение на сессию и отправить запрос на разбор.

**Материалы** — [иконка](../../extension/src/panel/icon.png), [активация](activation.png), [разбор](analysis.png), [политика конфиденциальности](privacy.md). Опубликуйте политику по общедоступному HTTPS-адресу и укажите его в карточке. В кабинете выберите **Unlisted**. Сверьте декларацию данных с политикой и заполните поле контакта поддержки.

## Инструкция для ревью

В закрытом поле для тестирования укажите одноразовый код, адрес поддерживаемого урока и, если требуется, данные отдельного тестового аккаунта Beyim. Проверьте доступ к уроку и срок кода перед подачей. Выпустите новый код, если предыдущий был использован до завершения ревью или истёк.

1. Установите расширение. На экране активации введите код.
2. Войдите в Beyim тестовым аккаунтом и откройте указанное упражнение. Нажмите Beyim Solver в меню расширений Chrome.
3. Прочитайте уведомление о передаче данных, согласитесь и нажмите «Разобрать задание». Дождитесь вопроса, предложенного ответа и объяснения.
4. При необходимости нажмите «Отправить ответ» и проверьте результат на тестовом упражнении.

После одобрения отправьте первому тестировщику ссылку магазина и личный код. Попросите пройти установку на чистом профиле Chrome с другой сети и проверить упражнение с рисунком. После успешной проверки выдайте остальные коды.
