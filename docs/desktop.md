# Настольный Beyim Solver

Приложение запускает Playwright и поддерживает OpenRouter, Groq и локальную Ollama.

- Windows. Запустите `Install.cmd`, затем `Start.cmd`. Используйте Python 3.14 с Tkinter.
- Linux. Установите Python 3.10+ с Tkinter и запустите `./Install.sh`, затем `./Start.sh`. Если Chromium не стартует из-за системных библиотек, запустите `./.venv/bin/python -m playwright install-deps chromium`.
- Для Ollama скачайте модели через `Download-models.cmd` или `./Download-models.sh`.

Дальнейшие команды с путём `.venv\Scripts\python.exe` приведены для Windows. На Linux используйте `./.venv/bin/python`.

## Запуск с OpenRouter (по умолчанию)

1. Создайте API-ключ в [OpenRouter](https://openrouter.ai/keys) и при необходимости пополните баланс. Программа не управляет биллингом и не может ограничить расходы аккаунта.
2. Закройте старое окно приложения и запустите **Start.cmd**.
3. Во вкладке «Подключение» выберите `openrouter`, вставьте ключ в скрытое поле «API-ключ Groq / OpenRouter». По умолчанию используется `qwen/qwen3.8-27b`, поддерживающая текст и изображения. Список доступных моделей подгружается из OpenRouter.
4. Нажмите **Проверить ИИ**, затем **Тест ИИ**. Второй тест отправляет контрольное уравнение в выбранный сервис и не обращается к аккаунту Beyim.
5. Укажите адрес урока, нажмите **Открыть Beyim**, войдите и откройте вопрос. **Прочитать вопрос** проверяет распознавание; **Только решение** получает ответ без отправки на сайт.
6. **Отправить один ответ** или **Автопрохождение** выбирает и отправляет ответы. **Остановить** и Escape прерывают ожидание и предотвращают новые действия.

### Вариант с Groq

Выберите `groq` в поле «Сервис ИИ» и вставьте ключ из [консоли Groq](https://console.groq.com/keys). Для бесплатной работы оставайтесь на Free Plan. Модель задаётся полем `groq_model`; по умолчанию это та же `qwen/qwen3.8-27b`.

Ключ находится только в памяти текущего запуска, не сохраняется в config.json или журнал. Для командной строки поддерживаются переменные окружения `OPENROUTER_API_KEY` и `GROQ_API_KEY`. В выбранный облачный сервис передаются текст вопроса, варианты и, если нужно, JPEG-снимок блока задания. Пароль, cookies и профиль браузера не отправляются.

Ollama для облачного режима не нужна; её можно закрыть. При временном HTTP 429 приложение ждёт `Retry-After` (до 60 секунд), максимум два повтора в пределах общего таймаута. При длительном лимите оно останавливается. Это не обходит дневную квоту сервиса. Ответ HTTP 402 у OpenRouter означает нехватку кредитов: пополните баланс на [openrouter.ai/credits](https://openrouter.ai/credits) или выберите бесплатную модель с суффиксом `:free`; для бесплатных моделей может потребоваться разрешить их в настройках приватности аккаунта OpenRouter. Успешно разобранные ответы кэшируются в памяти текущего запуска (до 128); ключ кэша учитывает сервис, модель, весь вопрос, порядок вариантов и содержимое снимка. Кэш не подтверждает правильность ответа.

Для модели `qwen/qwen3.8-27b` в Groq по умолчанию отключается внутреннее рассуждение, чтобы сократить задержку; параметр `thinking: true` включает его. В OpenRouter `thinking: true` запрашивает высокий уровень рассуждения. Скорость реального API требует проверки с вашим ключом. Бесплатные лимиты и доступность сервиса зависят от аккаунта и региона.

**Текущая граница поддержки:** распознавание `/assessment/...` ещё не исправлено: присланные HTML содержали экран загрузки. Смена ИИ не устраняет эту ошибку. Для него нужна разметка уже загруженного вопроса. Адаптер `/ai/topicFeed/...` и локальные тестовые формы сохранены.

При установке на другом компьютере нужны Python 3.14 с Tkinter и Microsoft Edge. **Install.cmd** ставит зависимости; отдельная загрузка Chromium и SDK облачных сервисов не требуется.

## Локальная Ollama

Выберите `ollama` в поле «Сервис ИИ». Адрес сервера и модели находятся во вкладке «Локальная Ollama». **Download-models.cmd** скачивает обе модели и проверяет локальный цикл. API-ключ в этом режиме не используется.

## Режим для 8 ГБ памяти

По умолчанию используются бесплатные локальные модели: текстовая `qwen3:1.7b` и `qwen3-vl:2b` для рисунков. Установите обе через **Download-models.cmd**. Интернет нужен для загрузки, API-ключ и подписка не нужны.

Контекст ограничен 4096 токенами, ответ — 768 токенами, внутреннее рассуждение отключено. Модели проекта выгружаются перед решением и после каждого ответа, включая остановку. Это снижает занятость памяти, но повторная загрузка замедляет следующее задание. Два окна обновлённого решателя не могут одновременно отправлять запросы. Если в Ollama работает посторонняя модель, решатель попросит освободить её память.

Изображения ограничены 1400 пикселями по большей стороне, без увеличения маленьких рисунков. Слишком длинный блок требует уточнить селектор, чтобы не потерять читаемость. Приложение не закрывает другие программы. На 8 ГБ оставьте минимум вкладок браузера; фактическое потребление зависит от Windows и других приложений. Меньшая модель может чаще ошибаться: низкая уверенность или неподтверждённый ответ останавливают автоматизацию.

После обновления закройте старое окно решателя и запустите **Start.cmd** снова.

## Что поддерживается

- Упражнения Beyim на страницах `https://beyim.ai/ru/ai/topicFeed/...`: скрытые radio/checkbox, подписи вариантов, таблицы и текстовые формулы, карусели упражнений, несколько блоков на странице.
- После проверки ожидается фактический признак правильного ответа `label.answerTrue`. Одна только доступность кнопки не считается успехом.
- Правильно решённые упражнения пропускаются. Бот сначала открывает первое незавершённое упражнение, в том числе если карусель была перелистана вручную.
- Обычные формы с `fieldset` / `radiogroup`: одиночный и множественный выбор. Текстовый ответ включается отдельным CSS-селектором.
- Ограничение числа заданий, проверка структуры ответа модели и остановка при изменении задания во время генерации, низкой уверенности, неоднозначной разметке или отсутствии подтверждённого перехода.
- Формат ответа Ollama ограничен типом задания: одиночный выбор требует один существующий ID, множественный — список ID, текстовый — текст. При ошибке формата выполняется одна попытка исправления без отправки в Beyim. Низкая уверенность не запускает повторную попытку.
- Рисунок в блоке задания: бот автоматически использует модель из поля «Модель для рисунков» (по умолчанию `qwen3-vl:2b`), если основная модель не поддерживает `vision`. Передаётся снимок только блока задания локальному Ollama. Для установки: `ollama pull qwen3-vl:2b`. Если модель отсутствует, сообщение содержит точную команду установки.
- Во время ожидания отображаются текущий этап и прошедшее время. На компьютере без дискретной видеокарты обработка изображения может занимать несколько минут; для неё предусмотрен отдельный таймаут.

Автопрохождение ограничено упражнениями открытой страницы. Оно не запускает оценивание по таймеру, не переходит само к следующему разделу и не выбирает предметы. Интерфейс оценивания, drag-and-drop, аудио и задания с несколькими текстовыми полями не проверены и не заявлены как поддерживаемые. Для иной структуры страницы есть вкладка «Распознавание страницы»; без подходящего адаптера бот остановится.

Модель может ошибаться даже при высокой собственной оценке уверенности. Если Beyim не подтвердил ответ, приложение останавливается вместо перебора вариантов. Журнал отправленных в текущем запуске вопросов защищает от повторного нажатия после ошибки. На новом запуске используется видимое состояние правильных ответов на сайте.

## Настройки

Приложение создаёт `config.json` при первом действии. Пример — `config.example.json`.

| Поле | Назначение |
|---|---|
| `provider` | `openrouter` (по умолчанию), `groq` или `ollama` |
| `openrouter_model` | Модель OpenRouter для текста и рисунков |
| `groq_model` | Модель Groq для текста и рисунков |
| `url` | Стартовая страница Beyim |
| `model` | Точное имя модели из `ollama list` |
| `vision_model` | Модель для заданий с рисунками, по умолчанию `qwen3-vl:2b` |
| `vision_timeout` | Таймаут решения задания с рисунком: по умолчанию 420 секунд |
| `ollama_url` | Локальный адрес, по умолчанию `http://127.0.0.1:11434` |
| `browser` | `msedge`, `chrome` или пустая строка для Chromium |
| `max_questions` | Максимум заданий за одно нажатие «Автопрохождение» |
| `min_confidence` | Минимальная самооценка уверенности модели, по умолчанию 0.8; не гарантия правильности |
| `timeout` | Таймаут модели в секундах, по умолчанию 180 |
| `num_ctx` | Контекст 2048–4096 токенов; по умолчанию 4096 |
| `num_predict` | Максимальная длина ответа 256–1024 токена; по умолчанию 768 |
| `thinking` | Внутреннее рассуждение поддерживающих его моделей; по умолчанию false для скорости. Можно включить true и увеличить timeout |
| `transition_timeout` | Ожидание результата сайта, по умолчанию 15 секунд |

Пустые селекторы включают встроенное распознавание. `root` — CSS-селектор ровно одного блока задания; `question`, `options`, `input` ищутся внутри него. `submit`, `next`, `complete` ищутся на странице. Текст вопроса должен включать условия, таблицы и пояснения. После изменения структуры сайта сначала проверяйте «Прочитать вопрос».

## Если кнопка «Открыть Beyim» выдаёт ошибку библиотеки

Запускайте **Start.cmd**. **Install.cmd** использует Python 3.14 явно: создание окружения через `py -3` после установки новой версии Python могло оставить несовместимую библиотеку `greenlet`. Повторный запуск исправленного **Install.cmd** восстанавливает совместимый интерпретатор. Прямой запуск `main.py` также перенаправляется в окружение проекта.

## Если Ollama не подключается

Запускайте приложение непосредственно в Windows. WSL здесь не нужен: обе программы обращаются к одному `127.0.0.1`.

```powershell
ollama list
curl.exe --connect-timeout 3 --max-time 5 http://127.0.0.1:11434/api/tags
```

Если сервер выключен, откройте Ollama из меню «Пуск» или выполните `ollama serve`. Сообщение `address already in use` означает занятый порт: второй сервер запускать не нужно. Если отсутствует модель: `ollama pull qwen3:1.7b`. Не требуется отключать брандмауэр или открывать порт в локальную сеть.

## Проверки разработки

```powershell
.\.venv\Scripts\python.exe main.py --doctor
.\.venv\Scripts\python.exe main.py --smoke-test
.\.venv\Scripts\python.exe main.py --vision-smoke-test
.\.venv\Scripts\python.exe main.py --full-smoke-test
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты браузера запускаются в headless Edge на локальных HTML-страницах и не обращаются к аккаунту. Проверяются выбор вариантов, снятие лишних checkbox, смена вопроса, отмена, повторы, неоднозначные блоки, hidden inputs и карусели Beyim. `--smoke-test` обращается к выбранному сервису с контрольным уравнением. Для OpenRouter в командной строке нужен OPENROUTER_API_KEY, для Groq — GROQ_API_KEY; `--provider ollama` выбирает локальный режим без изменения настроек.

`--vision-smoke-test` проверяет полный цикл с реальной vision-моделью на локальном рисунке: чтение, переключение модели, снимок, решение, выбор ответа и однократная отправка в тестовую HTML-страницу. `--full-smoke-test` дополнительно проходит три текстовых задания до рисунка и ещё три после него, проверяя выгрузку моделей через Ollama. Аккаунт Beyim не используется. Скриншоты результата сохраняются в `.state/verification/`.

## Данные

Пароль вводится только на сайте. Профиль браузера с авторизацией хранится в `.state/browser/`, исключён из Git и архива исходников. В режиме Ollama тексты передаются только локальному серверу. В режиме OpenRouter вопрос и снимок передаются по HTTPS на openrouter.ai, который пересылает их выбранному провайдеру модели; хранение зависит от настроек аккаунта OpenRouter. В режиме Groq запросы идут по HTTPS только на api.groq.com. Журнал решения виден в окне. Сведения о командах и ошибках сохраняются в `.state/diagnostic.log` (до двух файлов по 500 КБ), без автоматического сохранения вопросов и ответов. Не передавайте другим людям папку `.state` целиком.

Документация использованных API: [Ollama Chat](https://docs.ollama.com/api/chat), [Ollama Models](https://docs.ollama.com/api/tags), [Playwright](https://playwright.dev/python/docs/api/class-browsertype).

Документация OpenRouter: [быстрый старт](https://openrouter.ai/docs/quickstart), [ключи](https://openrouter.ai/keys), [модели](https://openrouter.ai/models), [лимиты](https://openrouter.ai/docs/api-reference/limits).

Документация Groq: [изображения](https://console.groq.com/docs/vision), [лимиты](https://console.groq.com/docs/rate-limits), [модель и режим рассуждения](https://console.groq.com/docs/model/qwen/qwen3.8-27b).
