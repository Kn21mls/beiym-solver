# Beyim Solver

Beyim Solver читает упражнения Beyim и предлагает ответ с объяснением. В тестах по теме отправка остаётся за пользователем.

| Задача | С чего начать |
|---|---|
| Установить расширение Chrome или Safari на Mac | [Расширение и сборки](extension/README.md) |
| Запустить общий API и выдать приглашения | [Сервер и выпуск беты](docs/store/README.md) |
| Запустить настольное приложение на Windows или Linux | [Настольное приложение](docs/desktop.md) |

Разработка ведётся в `main`. Для сборки расширения используйте Node.js 24. CI запускает серверные и настольные тесты на Python 3.14 и проверяет расширение на тестовых страницах Chromium.

- `extension/` содержит исходники браузерного расширения, сборку и тесты TypeScript.
- `server/` содержит FastAPI, SQLite и команды для приглашений.
- `beyim_solver/` содержит настольное приложение и общие клиенты ИИ.
- `tests/` содержит браузерные проверки и HTML-фикстуры.
- `macos/` содержит помощник запуска локального сервера из Safari.
