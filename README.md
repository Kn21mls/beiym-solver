# Beyim Solver для Linux

Приложение для Linux: Python + Playwright, облачный OpenRouter или Groq, либо локальная Ollama. Открывает Beyim в отдельном окне Chromium, читает упражнение, получает ответ от модели, выбирает вариант, нажимает «Проверить» и переходит к следующему упражнению. Облачные сервисы требуют API-ключ; Ollama работает локально без ключа.

Версия для Windows находится в ветке `windows`, версия для macOS — в ветке `mac`. Эта ветка (`linux`) содержит версию для Linux.

## Требования

- Linux с графическим рабочим столом (X11 или Wayland через XWayland). В SSH без `DISPLAY` окно не откроется.
- Python 3.10 или новее; рекомендуется 3.14. Нужны `venv`, `pip` и Tkinter.
  - Debian/Ubuntu: `sudo apt install python3 python3-venv python3-tk`
  - Fedora: `sudo dnf install python3 python3-tkinter`
  - Arch: `sudo pacman -S python tk`
- Интернет для установки зависимостей и Chromium.
- Ollama нужна только для локального режима: [ollama.com/download/linux](https://ollama.com/download/linux).

## Установка

1. Склонируйте ветку `linux`:

   ```bash
   git clone -b linux https://github.com/Kn21mls/beiym-solver.git
   cd beiym-solver
   ```

2. Запустите установщик:

   ```bash
   chmod +x Install.sh Start.sh Download-models.sh
   ./Install.sh
   ```

   Скрипт создаёт `.venv`, ставит зависимости и скачивает Chromium для Playwright (около 150 МБ).

3. Если Chromium не запускается из-за отсутствующих системных библиотек, установите их:

   ```bash
   ./.venv/bin/python -m playwright install-deps
   ```

   Команда использует `sudo` и поддерживает Debian/Ubuntu и близкие дистрибутивы. На других дистрибутивах установите зависимости Chromium вручную по сообщению Playwright.

## Обновление

Перед обновлением закройте приложение, затем в папке репозитория выполните:

```bash
git pull --ff-only origin linux
./Install.sh
```

`git pull` получит последние изменения, а повторный запуск `Install.sh` обновит Python-зависимости и Chromium, если это необходимо.

## Запуск с OpenRouter (по умолчанию)

1. Создайте API-ключ в [OpenRouter](https://openrouter.ai/keys) и при необходимости пополните баланс.
2. Запустите:

   ```bash
   ./Start.sh
   ```

3. Во вкладке «Подключение» выберите `openrouter`, вставьте ключ в скрытое поле «API-ключ Groq / OpenRouter». По умолчанию используется `qwen/qwen3.8-27b` (текст и изображения). Список моделей подгружается из OpenRouter.
4. Нажмите **Проверить ИИ**, затем **Тест ИИ**. Второй тест не обращается к аккаунту Beyim.
5. Укажите адрес урока, нажмите **Открыть Beyim**, войдите и откройте вопрос. **Прочитать вопрос** проверяет распознавание; **Только решение** получает ответ без отправки на сайт.
6. **Отправить один ответ** или **Автопрохождение** выбирает и отправляет ответы. **Остановить** и Escape прерывают ожидание и предотвращают новые действия.

### Вариант с Groq

Выберите `groq` в поле «Сервис ИИ» и вставьте ключ из [консоли Groq](https://console.groq.com/keys). Для бесплатной работы оставайтесь на Free Plan. Модель задаётся полем `groq_model`.

Ключ находится только в памяти текущего запуска, не сохраняется в `config.json` или журнал. Для командной строки поддерживаются переменные окружения `OPENROUTER_API_KEY` и `GROQ_API_KEY`. В выбранный облачный сервис передаются текст вопроса, варианты и, если нужно, JPEG-снимок блока задания. Пароль, cookies и профиль браузера не отправляются.

При временном HTTP 429 приложение ждёт `Retry-After` (до 60 секунд), максимум два повтора в пределах общего таймаута. Ответ HTTP 402 у OpenRouter означает нехватку кредитов: пополните баланс на [openrouter.ai/credits](https://openrouter.ai/credits) или выберите бесплатную модель с суффиксом `:free`. Для бесплатных моделей может потребоваться разрешить их в настройках приватности OpenRouter. Успешно разобранные ответы кэшируются в памяти текущего запуска (до 128); ключ кэша учитывает сервис, модель, вопрос, порядок вариантов и снимок.

Для модели `qwen/qwen3.8-27b` в Groq по умолчанию отключается внутреннее рассуждение, чтобы сократить задержку; параметр `thinking: true` включает его. В OpenRouter `thinking: true` запрашивает высокий уровень рассуждения.

## Локальная Ollama

Выберите `ollama` в поле «Сервис ИИ». Адрес сервера и модели находятся во вкладке «Локальная Ollama». **Download-models.sh** скачивает обе модели и проверяет локальный цикл. API-ключ в этом режиме не используется.

По умолчанию используются бесплатные локальные модели: текстовая `qwen3:1.7b` и `qwen3-vl:2b` для рисунков. Контекст ограничен 4096 токенами, ответ — 768 токенами, внутреннее рассуждение отключено. Модели выгружаются перед решением и после каждого ответа. На машине с небольшим объёмом памяти оставьте минимум вкладок браузера; меньшая модель может чаще ошибаться.

## Браузер

На Linux по умолчанию используется Chromium, установленный Playwright (поле `browser` пустое). Если установлены Microsoft Edge или Google Chrome, можно указать `msedge` или `chrome`. Профиль с авторизацией хранится в `.state/browser/` и исключён из Git.

Если Chromium падает с ошибкой sandbox, запускайте приложение от обычного пользователя (не от root) и установите системные зависимости через `./.venv/bin/python -m playwright install-deps`. На Wayland нужен установленный XWayland.

## Что поддерживается

- Упражнения Beyim на страницах `https://beyim.ai/ru/ai/topicFeed/...`: скрытые radio/checkbox, подписи вариантов, таблицы и текстовые формулы, карусели упражнений, несколько блоков на странице.
- После проверки ожидается фактический признак правильного ответа `label.answerTrue`. Одна только доступность кнопки не считается успехом.
- Правильно решённые упражнения пропускаются. Бот сначала открывает первое незавершённое упражнение, в том числе если карусель была перелистана вручную.
- Обычные формы с `fieldset` / `radiogroup`: одиночный и множественный выбор. Текстовый ответ включается отдельным CSS-селектором.
- Ограничение числа заданий, проверка структуры ответа модели и остановка при изменении задания во время генерации, низкой уверенности, неоднозначной разметке или отсутствии подтверждённого перехода.
- Рисунок в блоке задания: передаётся снимок только блока задания выбранной модели. В локальном режиме используется поле «Модель для рисунков».
- Автопрохождение ограничено упражнениями открытой страницы. Оно не запускает оценивание по таймеру, не переходит само к следующему разделу и не выбирает предметы.

Модель может ошибаться даже при высокой собственной оценке уверенности. Если Beyim не подтвердил ответ, приложение останавливается вместо перебора вариантов. Журнал отправленных в текущем запуске вопросов защищает от повторного нажатия после ошибки.

## Настройки

Приложение создаёт `config.json` при первом действии. Пример — `config.example.json`.

| Поле | Назначение |
|---|---|
| `provider` | `openrouter` (по умолчанию), `groq` или `ollama` |
| `openrouter_model` | Модель OpenRouter для текста и рисунков |
| `groq_model` | Модель Groq для текста и рисунков |
| `url` | Стартовая страница Beyim |
| `model` | Точное имя модели из `ollama list` |
| `vision_model` | Модель для заданий с рисунками, по умолчанию `qwen3-vl:2b` |
| `vision_timeout` | Таймаут решения задания с рисунком: по умолчанию 420 секунд |
| `ollama_url` | Локальный адрес, по умолчанию `http://127.0.0.1:11434` |
| `browser` | Пустая строка для Chromium Playwright, `msedge` или `chrome` |
| `max_questions` | Максимум заданий за одно нажатие «Автопрохождение» |
| `min_confidence` | Минимальная самооценка уверенности модели, по умолчанию 0.8 |
| `timeout` | Таймаут модели в секундах, по умолчанию 180 |
| `num_ctx` | Контекст 2048–4096 токенов; по умолчанию 4096 |
| `num_predict` | Максимальная длина ответа 256–1024 токена; по умолчанию 768 |
| `thinking` | Внутреннее рассуждение поддерживающих его моделей |
| `transition_timeout` | Ожидание результата сайта, по умолчанию 15 секунд |

Пустые селекторы включают встроенное распознавание. `root` — CSS-селектор ровно одного блока задания; `question`, `options`, `input` ищутся внутри него. `submit`, `next`, `complete` ищутся на странице. После изменения структуры сайта сначала проверяйте «Прочитать вопрос».

## Если Tkinter не найден

Установите пакет Tkinter для вашего дистрибутива и заново запустите `./Install.sh`:

```bash
sudo apt install python3-tk        # Debian/Ubuntu
sudo dnf install python3-tkinter   # Fedora
sudo pacman -S tk                  # Arch
```

## Если Chromium или Playwright не запускается

```bash
./.venv/bin/python -m playwright install chromium
./.venv/bin/python -m playwright install-deps
./.venv/bin/python main.py --doctor
```

`install-deps` требует `sudo`. Если дистрибутив не поддерживается, установите перечисленные Playwright библиотеки вручную.

## Если Ollama не подключается

```bash
ollama list
curl --connect-timeout 3 --max-time 5 http://127.0.0.1:11434/api/tags
```

Если сервер выключен, выполните `ollama serve` или включите службу `ollama` через systemd. Если отсутствует модель: `ollama pull qwen3:1.7b`.

## Проверки разработки

```bash
./.venv/bin/python main.py --doctor
./.venv/bin/python main.py --smoke-test
./.venv/bin/python main.py --vision-smoke-test
./.venv/bin/python main.py --full-smoke-test
./.venv/bin/python -m unittest discover -s tests -v
```

Тесты браузера запускаются в headless Chromium на локальных HTML-страницах и не обращаются к аккаунту. `--smoke-test` обращается к выбранному сервису с контрольным уравнением. Для OpenRouter нужен `OPENROUTER_API_KEY`, для Groq — `GROQ_API_KEY`; `--provider ollama` выбирает локальный режим.

## Данные

Пароль вводится только на сайте. Профиль браузера с авторизацией хранится в `.state/browser/`, исключён из Git. В режиме Ollama тексты передаются только локальному серверу. В режиме OpenRouter запросы идут по HTTPS на openrouter.ai, который пересылает их выбранному провайдеру модели; хранение зависит от настроек аккаунта OpenRouter. В режиме Groq запросы идут на api.groq.com. Сведения о командах и ошибках сохраняются в `.state/diagnostic.log` (до двух файлов по 500 КБ), без автоматического сохранения вопросов и ответов. Не передавайте другим людям папку `.state` целиком.

Документация OpenRouter: [быстрый старт](https://openrouter.ai/docs/quickstart), [ключи](https://openrouter.ai/keys), [модели](https://openrouter.ai/models), [лимиты](https://openrouter.ai/docs/api-reference/limits).

Документация Groq: [изображения](https://console.groq.com/docs/vision), [лимиты](https://console.groq.com/docs/rate-limits).

Документация Playwright: [Python](https://playwright.dev/python/docs/api/class-browsertype).
