# Beyim Solver

Локальное приложение для Windows: Python + Playwright + Ollama. Открывает Beyim в отдельном окне Edge, читает упражнение, получает ответ от установленной модели, выбирает вариант, нажимает «Проверить» и переходит к следующему упражнению. API-ключи не нужны.

## Запуск на этом компьютере

1. Запустите Ollama, если она закрыта. `qwen3:4b` уже установлена и проверена.
2. Дважды нажмите **Start.cmd**.
3. Нажмите **Проверить Ollama**, затем **Открыть Beyim**.
4. Войдите в аккаунт в открывшемся Edge и откройте нужную тему с упражнениями. Вход сохранится для следующих запусков. Это отдельный профиль: вход из вкладки Codex автоматически не переносится.
5. Нажмите **Прочитать вопрос**, чтобы увидеть распознанный текст. **Только решение** показывает ответ без отправки.
6. **Отправить один ответ** обрабатывает одно упражнение. **Автопрохождение** проходит упражнения открытой страницы до завершения, ошибки или выбранного лимита.
7. **Остановить** или Escape прекращает новые действия и прерывает запрос к Ollama. Уже отправленный ответ отменить нельзя.

При первом запуске на другом компьютере нужен Python 3.11+ с Tkinter, Microsoft Edge и Ollama. Запустите **Install.cmd**, затем установите модель командой `ollama pull qwen3:4b`. Установщик создаёт `.venv` и ставит Playwright из PyPI. Edge используется установленный; отдельный Chromium скачивать не требуется. Для Chromium можно задать `"browser": ""` в config.json и выполнить `.venv\Scripts\python.exe -m playwright install chromium`.

## Что поддерживается

- Упражнения Beyim на страницах `https://beyim.ai/ru/ai/topicFeed/...`: скрытые radio/checkbox, подписи вариантов, таблицы и текстовые формулы, карусели упражнений, несколько блоков на странице.
- После проверки ожидается фактический признак правильного ответа `label.answerTrue`. Одна только доступность кнопки не считается успехом.
- Правильно решённые упражнения пропускаются. Бот сначала открывает первое незавершённое упражнение, в том числе если карусель была перелистана вручную.
- Обычные формы с `fieldset` / `radiogroup`: одиночный и множественный выбор. Текстовый ответ включается отдельным CSS-селектором.
- Ограничение числа заданий, проверка структуры ответа модели и остановка при изменении задания во время генерации, низкой уверенности, неоднозначной разметке или отсутствии подтверждённого перехода.
- Рисунок в блоке задания: проверяется возможность `vision` у модели, затем локальной модели передаётся снимок только блока задания. Текстовая `qwen3:4b` на таких заданиях останавливается.

Автопрохождение ограничено упражнениями открытой страницы. Оно не запускает оценивание по таймеру, не переходит само к следующему разделу и не выбирает предметы. Интерфейс оценивания, drag-and-drop, аудио и задания с несколькими текстовыми полями не проверены и не заявлены как поддерживаемые. Для иной структуры страницы есть вкладка «Распознавание страницы»; без подходящего адаптера бот остановится.

Модель может ошибаться даже при высокой собственной оценке уверенности. Если Beyim не подтвердил ответ, приложение останавливается вместо перебора вариантов. Журнал отправленных в текущем запуске вопросов защищает от повторного нажатия после ошибки. На новом запуске используется видимое состояние правильных ответов на сайте.

## Настройки

Приложение создаёт `config.json` при первом действии. Пример — `config.example.json`.

| Поле | Назначение |
|---|---|
| `url` | Стартовая страница Beyim |
| `model` | Точное имя модели из `ollama list` |
| `ollama_url` | Локальный адрес, по умолчанию `http://127.0.0.1:11434` |
| `browser` | `msedge`, `chrome` или пустая строка для Chromium |
| `max_questions` | Максимум заданий за одно нажатие «Автопрохождение» |
| `min_confidence` | Минимальная самооценка уверенности модели, по умолчанию 0.8; не гарантия правильности |
| `timeout` | Таймаут модели в секундах, по умолчанию 180 |
| `thinking` | Внутреннее рассуждение поддерживающих его моделей; по умолчанию false для скорости. Можно включить true и увеличить timeout |
| `transition_timeout` | Ожидание результата сайта, по умолчанию 15 секунд |

Пустые селекторы включают встроенное распознавание. `root` — CSS-селектор ровно одного блока задания; `question`, `options`, `input` ищутся внутри него. `submit`, `next`, `complete` ищутся на странице. Текст вопроса должен включать условия, таблицы и пояснения. После изменения структуры сайта сначала проверяйте «Прочитать вопрос».

## Если Ollama не подключается

Запускайте приложение непосредственно в Windows. WSL здесь не нужен: обе программы обращаются к одному `127.0.0.1`.

```powershell
ollama list
curl.exe --connect-timeout 3 --max-time 5 http://127.0.0.1:11434/api/tags
```

Если сервер выключен, откройте Ollama из меню «Пуск» или выполните `ollama serve`. Сообщение `address already in use` означает занятый порт: второй сервер запускать не нужно. Если отсутствует модель: `ollama pull qwen3:4b`. Не требуется отключать брандмауэр или открывать порт в локальную сеть.

## Проверки разработки

```powershell
.\.venv\Scripts\python.exe main.py --doctor
.\.venv\Scripts\python.exe main.py --smoke-test
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты браузера запускаются в headless Edge на локальных HTML-страницах и не обращаются к аккаунту. Проверяются выбор вариантов, снятие лишних checkbox, смена вопроса, отмена, повторы, неоднозначные блоки, hidden inputs и карусели Beyim. `--smoke-test` обращается к реальной Ollama с контрольным уравнением.

## Данные

Пароль вводится только на сайте. Профиль браузера с авторизацией хранится в `.state/browser/`, исключён из Git и архива исходников. Тексты заданий отправляются только локальному Ollama; удалённые адреса сервера не принимаются. Журнал решения виден в окне и не сохраняется автоматически. Не передавайте другим людям папку `.state`.

Документация использованных API: [Ollama Chat](https://docs.ollama.com/api/chat), [Ollama Models](https://docs.ollama.com/api/tags), [Playwright](https://playwright.dev/python/docs/api/class-browsertype).
